# KEO public presentation site

A French landing page based on the `keo-udvi-ebp.md` source document.

- `/` — accessible overview of the KEO framework.
- `/assets/keo-emblem.svg` — original vector illustration.
- `/media/` — animated SVG motion graphic and explanation page. This is browser-rendered vector animation, not an MP4/WebM video.
- `.github/workflows/pages.yml` — deploys the static files to GitHub Pages on pushes to `main` or manual workflow dispatch.

This is an editorial presentation, not clinical advice, a certification, an independently verified audit, or evidence of affiliation with any organization named in the source document.
